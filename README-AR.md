# موقع محمد مصطفى: التنظيم والرفع

## هيكل المجلد (كل قسم منفصل تماماً)
```
site/
  index.html            الموقع نفسه (ما تعدّلش فيه)
  data/
    design.js           مشاريع قسم DESIGN  (مقسّمة: Branding / Social Media / Packaging / Print)
    video.js            مشاريع قسم VIDEO   (مقسّمة: Video Editing / Motion Graphics / Animation / Reels / Commercial)
    web.js              مشاريع قسم WEB     (قائمة واحدة، بدون فلتر)
  images/
    design/branding/  social-media/  packaging/  print/
    video/video-editing/  motion-graphics/  animation/  reels/  commercial/
    web/
  videos/video/<القسم-الفرعي>/
```
**القاعدة:** مشروع التصميم يتحط في `data/design.js` تحت القسم الفرعي بتاعه. صوره في `images/design/<القسم-الفرعي>/`. وكده في الفيديو والويب. مفيش حاجة بتتخلط.

## أخطاء شائعة (لو الصفحة فاضية أو بتعرض المحتوى التجريبي)
1. افتح الصفحة واضغط F12 ثم تبويب Console. السطر الأحمر بيقولك المشكلة.
2. أغلب الأسباب: مشروع ما اتقفلش بـ `}` أو ناقص فاصلة بين مشروعين، فالملف كله بيتتجاهل.
3. أسماء الملفات والمجلدات لازم تطابق حروفها بالظبط (الاستضافة بتفرّق بين الكبير والصغير و`.jpg` و`.JPG`).
4. لازم تفتح `index.html` من نفس المجلد اللي فيه `data/` و`images/`، ما تنقلوش لوحده.

## إضافة مشروع
1. ضع صور المشروع في مجلد قسمه (مثال: `images/design/branding/atlas/`).
2. افتح ملف القسم (مثال: `data/design.js`) وانسخ المثال داخل القسم الفرعي الصح، وفك التعليق، وعدّل البيانات والمسارات.
3. احفظ وارفع المجلد من جديد.

لو كتبت اسم قسم فرعي غلط، الصفحة بتكتب تحذير في الـ Console (F12) باسم الأقسام الصح.

## ما يحصل تلقائياً لأي مشروع
حركة الماوس، ظهوره مع السكرول، الفلتر (في التصميم والفيديو)، صفحة دراسة الحالة، زر "اطلب هذه الخدمة" بالخدمة المناسبة للقسم، وإطار القسم في الصفحة الرئيسية.
أول ما تضيف مشاريع حقيقية في قسم، المشاريع التجريبية بتاعته بتختفي، والإطار في الرئيسية بيعرض صور شغلك. (القسم اللي ما فيهوش شغل حقيقي يفضل بالتجريبي.)

## الرفع (مجاني، حوالي ٥ دقائق)
1. افتح https://app.netlify.com/drop وسجّل بحساب مجاني.
2. اسحب مجلد `site` كله، وبيطلعلك رابط الموقع.
بدائل: Cloudflare Pages أو Vercel أو GitHub Pages.

## نموذج "اطلب هذه الخدمة"
النموذج كامل، لكن لسه مش متصل بسيرفر: العميل بيبعت الملخص بزر واتساب أو البريد. للربط بسيرفر ضع رابطه في `REQUEST_ENDPOINT` داخل `index.html`.
(يرسل multipart/form-data: الحقل `payload` بصيغة JSON، والملفات في `files`.)

## أحجام الملفات
صور: عرض ١٦٠٠ بكسل وحوالي ٢٠٠–٤٠٠KB. فيديو: mp4 مضغوط أقل من ١٠–١٥MB.

## خلفية قسم الويب
الصورة في `images/backgrounds/web.jpg`. لتغييرها استبدل الملف بصورة جديدة بنفس الاسم (يفضّل 1920×1080 أو أكبر).

## إضافة مشروع جديد بدون تعديل يدوي
شغّل من فولدر الموقع (محتاج Python، ويفضل `pip install pillow`):

    python add_project.py --section "Social Media" --title "اسم المشروع" --folder "مسار فولدر الصور" --half

السكريبت بيعمل فولدر للمشروع، وبينسخ الصور ويرتبها، وبيضيف المشروع في أول القسم في `data/design.js`. استخدم `--last` لو عايزه في آخر القسم، و`--cover` لاختيار الغلاف. الأقسام: Branding / Social Media / Packaging / Print.
